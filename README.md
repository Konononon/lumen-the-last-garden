# LUMEN · 마지막 달빛 정원

작고 밀도 높은 판타지 정원을 자유롭게 탐험하는 완결형 3D 어드벤처입니다. 세 곳의 퍼즐을 풀어 잃어버린 별빛을 모으고 달의 문을 깨웁니다. 6개의 이야기 기록과 6마리의 숨은 빛나비도 찾을 수 있습니다.

## 실행

`start-game.bat`을 더블 클릭하고 브라우저에서 **http://127.0.0.1:5173**을 엽니다. 실행 창은 플레이 중 열어 두세요. Node.js 20.19 이상이 필요합니다.

```powershell
npm install
npm run dev
```

## 조작

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 카메라 기준 이동 |
| Shift | 달리기 |
| E / 화면의 상호작용 버튼 | 가까운 대상과 대화·퍼즐 조작 |
| 바닥 클릭 | 길을 찾아 이동 |
| 화면 드래그 / 휠 | 카메라 회전 / 확대·축소 |
| Q | 등불 파동, 반경 4.5m의 숨은 빛나비 수집 |
| J / M | 기록장 / 지도 |
| F | 감상 모드 |
| Esc | 메뉴 / 열린 패널 닫기 |

모바일 화면에는 이동 버튼과 등불 버튼이 표시됩니다. 여정은 같은 브라우저와 주소에 자동 저장됩니다. 메뉴에서 음소거, 전체 화면, 화면 품질, 재시작을 선택할 수 있습니다.

## 직접 만든 에셋

외부의 모델·텍스처·음악·샘플을 사용하지 않았습니다.

- `scripts/create-models.mjs`: 곡선, 회전체, 직접 구성한 메시로 나무, 꽃, 풀, 고사리, 버섯, 유적, 종, 거울, 등불, 우물, 여행자, 정원지기 등 17종을 제작합니다. `public/assets/garden.glb`에 저장했습니다.
- `src/world.ts`: 지형, 수면·폭포 셰이더, 지형 질감, 빛과 입자, 건축물, 식생 배치를 직접 구성합니다. 식생은 인스턴싱으로 렌더링합니다.
- `scripts/create-audio.py`: 직접 작곡한 64초 루프 음악, 종, 바람, 물소리, 발걸음, 발견 효과음 등 11개 WAV 파일을 사인파·노이즈 합성으로 제작합니다.
- 지도, 기호, UI는 직접 작성한 SVG·Canvas·CSS입니다. 글꼴은 운영체제에 설치된 글꼴을 사용합니다.

```powershell
npm run assets   # 원본 제작 코드로 모델과 사운드 재생성 (Python 필요)
npm test         # 퍼즐, 저장, 충돌, 경로 검증
npm run build    # 타입 검사와 배포 빌드
npm run playtest # 별도 테스트 브라우저에서 실제 조작 및 화면 검증
```

## 구성

Three.js + TypeScript + Vite. `src/simulation.mjs`는 진행과 저장 상태, `src/navigation.mjs`는 경로 탐색, `src/world.ts`는 3D 표현, `src/ui.ts`는 한국어 인터페이스, `src/audio.ts`는 사운드를 담당합니다. 빌드 결과는 `dist/`에 생성됩니다. `npm run preview`로 빌드 결과를 확인할 수 있습니다.

개발 서버에서만 테스트용 `window.__LUMEN` 진단 API를 제공합니다. 배포 빌드에는 테스트 위치 이동 기능이 포함되지 않습니다.

## 현재 버전 검증

타입 검사와 배포 빌드, 게임 규칙 테스트 8개를 통과했습니다. 별도 브라우저에서 시작 화면, 이동, 카메라, NPC 대화, 모든 상호작용 지점의 경로, 입구에서 우물까지 실제 자동 이동, 지도, 종 퍼즐을 확인했습니다. 전체 자동 플레이 검증은 CPU 부하 때문에 중단했습니다. 이후 브라우저 테스트를 재실행하지 않았습니다.
